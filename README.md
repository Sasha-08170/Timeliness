##  Описание стилей таймлайна

Этот проект создаёт **чистую, современную вертикальную шкалу (timeline)** с такими особенностями:

-  **Зелёная линия прогресса** с плавным градиентом.  
-  **Аккуратные точки поверх линии**, выделяющиеся мягкой тенью.  
-  **Карточки описаний** с белым фоном и лёгкими тенями для визуальной глубины.  
-  **Адаптация под мобильные устройства** — элементы уменьшаются и сохраняют читаемость.  
-  **Плавные анимации при наведении** — карточки немного поднимаются и меняют фон.
